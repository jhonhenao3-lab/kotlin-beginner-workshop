# Taller de Kotlin para Principiantes (kotlin-beginner-workshop)

**Estudiante:** JHON FABER HENAO ACEVEDO 
**Curso/Asignatura:** DESARROLLO DE APLICATIVOS MOVILES 

## Descripción
Este repositorio contiene la solución a los 8 ejercicios prácticos del taller de Kotlin, abarcando conceptos básicos como tipos de datos, estructuras de control (`when`, `if`), ciclos (`for`), colecciones (`List`, `MutableList`), funciones, Programación Orientada a Objetos (clases y objetos) y manejo seguro de nulos (*Null Safety*).
